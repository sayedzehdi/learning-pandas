# 🐼 Learning pandas with Python

A free, illustrated course that takes you from your first DataFrame to professional-grade pandas, **written for pandas 3.x**.

Every lesson is a Jupyter notebook you can run on **Kaggle** (nothing to install) or on your own computer.
Every key idea gets a picture, because things like merges, groupby and reshaping make much more sense once you can *see* them.

![The pandas workflow](images/lesson01_pandas_workflow.png)

## Who it's for
You know basic Python (variables, lists, dictionaries, functions) and want to analyse data with it.
No prior pandas experience needed.

## The running dataset: Bean & Byte Café ☕
The whole course follows one year of sales at a fictional three-branch coffee shop.
The data is deliberately realistic, so it comes with messy spellings, missing values and duplicates for you to clean.
It's generated by [`data/generate_cafe_sales.py`](data/generate_cafe_sales.py), so you can rebuild it anytime.

## Run it

**On Kaggle:** open the lesson notebook on Kaggle and click **Copy & Edit**.

**Locally:**
```bash
git clone https://github.com/sayedzehdi/learning-pandas.git
cd learning-pandas
pip install -r requirements.txt
jupyter lab
```

## Repo layout
```
data/        cafe_sales.csv and the script that generates it
images/      all lesson illustrations (PNG)
lessons/     one folder per lesson, each with its notebook
tools/       scripts that build the notebooks, figures and Kaggle exports
```

## For maintainers
```bash
python data/generate_cafe_sales.py         # rebuild the dataset
python tools/make_lesson01_figures.py      # rebuild Lesson 1 illustrations
python tools/build_lesson01.py             # rebuild the Lesson 1 notebook
python tools/export_for_kaggle.py --user <github-username>   # Kaggle copies with image URLs
```
